# data/

Hand-curated from MDC's public catalog (mdc.edu). Agents may **only** choose programs from here.
Every entry needs a `source_url`. Numbers that are guesses get `"estimate": true`.

| File | Contents |
|---|---|
| `careers.json` | Supported careers + keywords used to filter programs |
| `mdc_programs.json` | MDC programs (certificates, A.S., A.A., B.S./B.A.S.) |
| `transfer_agreements.json` | 2+2 / articulation agreements with universities |
| `costs.json` | Tuition per credit (MDC + transfer universities), fees, books |

Entries below are templates — replace `TODO` with real data.
