# Demo & Pitch (3 min) — draft

Setup: Chrome with the extension loaded, on `www.mdc.edu`, monitor at the booth. `DEMO_MODE` ready as backup.

1. **Hook (20 s)** — "Maria is on MDC's website. She wants to work in cybersecurity. Where does she even click?"
2. **Problem (20 s)** — programs, transfer agreements, tuition and aid are scattered across dozens of pages.
3. **Live demo (100 s)**
   - Shark 🦈 bottom-right → **Group Chat** → "New group": add Career Explorer, MDC Pathway Advisor,
     Time & Cost, Financial Aid.
   - "Quiero trabajar en ciberseguridad, tengo poco dinero y trabajo medio tiempo" → advisors reply in turns,
     tokens + cost under each message (Spanish works too).
   - "I'm ready to go deeper" → flowchart: short / medium / long routes, all starting at MDC, entry points
     where she can already work, cost after aid, warnings. Download PDF.
   - Click the MDC A.S. box → panel closes → the guide highlights "Academics" → … → she lands on the real
     program page.
   - (10 s) Mixture mode: same advisors, one merged answer, total cost.
4. **How it works (25 s)** — Swarms: 6 specialized agents, two collaboration patterns, a writer agent that
   builds the roadmap from real MDC data, and a navigator agent that reads the page. Cost per conversation: $X.
5. **Impact & scale (15 s)** — works on any mdc.edu page; adding a program = adding data; bilingual for Miami.

Backup: `DEMO_MODE=true` + pre-recorded guide if Wi-Fi fails.
Judges' checklist: "What MDC is looking for" in [PRODUCT.md](PRODUCT.md).
