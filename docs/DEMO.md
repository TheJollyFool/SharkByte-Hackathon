# Demo & Pitch (3 min) — draft

1. **Hook (20 s)** — "Maria wants to be a cybersecurity specialist. Where does she start? How long? How much?"
2. **Problem (20 s)** — info scattered across catalogs, transfer agreements and job sites; students give up or pick the wrong program.
3. **Live demo (90 s)** — pick career → preferences → agents panel lights up (Swarms graph) → 3 routes:
   - Short: MDC certificate → job in ~1 year
   - Medium: A.S. → work + certifications
   - Long: A.A. → transfer (2+2) → B.S. → M.S.
   Show time + cost totals, workforce entry points, credentials. Scan the QR on the phone.
4. **How it works (30 s)** — 5 agents, 3 in parallel, real MDC data injected, cost per roadmap = $X.
5. **Impact & scale (20 s)** — adding a career = adding data; works for every MDC program.

Backup: `DEMO_MODE=true` serves cached roadmaps if Wi-Fi fails.
