# Requirements & Scope

> **Human-owned file.** The team (Piero, Adrian, Robert, Diego) writes and approves this, not an AI. Agents must treat it as
> read-only and must not build anything listed under "Out of scope". If a task seems to need
> something not listed here, stop and ask a human.

## Functional requirements (MVP — must ship)

| ID | Requirement | Covers |
|---|---|---|
| FR-1 | Student picks a career from a list of 5 showcase careers (free-text search is "should have", best effort) | MDC §1 |
| FR-2 | Career overview: description, responsibilities, qualifications, related careers | MDC §1 |
| FR-3 | Student sets preferences: budget, pace, full/part-time, existing credits | Personalized |
| FR-4 | System returns 2–4 routes; **step 1 of every route is a real MDC program** from `data/` | MDC §2, §5 |
| FR-5 | Each step shows credential, institution, duration, cost (estimates labeled) | MDC §2, §3 |
| FR-6 | Each route shows total time and total cost | MDC §3 |
| FR-7 | Routes show transfer steps with the agreement used (when applicable) | MDC §2 |
| FR-8 | Routes list certifications/licenses, internships, licensing exams | MDC §4 |
| FR-9 | Timeline marks the points where the student can start working | MDC §5 |
| FR-10 | List of alternative MDC programs for the same/related career | MDC §5 |
| FR-11 | Resources: exam prep, résumé, interviews | MDC §4 |
| FR-12 | Roadmap generated by the Swarms graph workflow (5 agents) | Swarms |
| FR-13 | Shareable link + QR code for each roadmap | Demo |
| FR-14 | Demo mode: cached roadmaps for the 5 showcase careers, works without Swarms | Demo safety |

## Non-functional requirements
- NFR-1 Mobile-first; usable on a phone from a QR scan.
- NFR-2 A roadmap loads in < 3 s from cache; live generation shows progress (agents panel).
- NFR-3 No prior knowledge of college programs needed to use it.
- NFR-4 No API keys in the repo or in the frontend bundle.
- NFR-5 Adding a career requires only data changes (`data/*.json`), no code.

## Should have (if time)
- Free-text career search (any career, best effort)
- Live "agents working" graph animation (high priority — it sells the Swarms track)
- Gemini model on ≥1 agent
- GoDaddy custom domain

## Out of scope (do NOT build)
- Login, accounts, user profiles, saving history
- Real-time course schedules / seat availability
- Financial aid applications or payments
- Chatbot / free conversation UI
- Admin panel / CMS for data
- Any track other than those in [TRACKS.md](TRACKS.md)

## Definition of done (MVP)
The 5 showcase careers each produce a valid roadmap (matches the schema) that a judge can open
from a QR code on their phone, and the demo runs end-to-end with `DEMO_MODE=true` and with it off.
